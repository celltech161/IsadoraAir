Hidden Track Detection

Diagnostic scan only -- suspected tracks are listed for human verification, nothing is changed. This reads each track's already-computed waveform analysis; it does not decode audio, and it never edits cue points, playout markers, or any Track row. Use the link on each result to open the track's existing detail/waveform page and confirm before doing anything else.
