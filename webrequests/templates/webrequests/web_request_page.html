Web Requests

Controls the public-site song-request feature end to end: whether it's on at all, which hours accept requests, and the rate/timeout knobs that govern how a request gets fulfilled. See also Django admin (Config > Web Request Configuration) for the same non-grid fields.

Off by default. Nothing syncs to the public site, nothing is polled, nothing is fulfilled, until this is on.

Rate & Timing

Requests beyond the per-hour cap stay pending and roll into the next hour's budget rather than being rejected. A request with no eligible slot within the lookahead window is reported as "no slot soon" (still queued, still eligible) instead of a plain "pending".
