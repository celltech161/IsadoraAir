# r0150 KanDrive workload mitigation and deterministic media regression

Ordinary road generation checks follow successful authoritative syncs.
KOGR's 30-minute retrieval slots start around :07 and :37 local time.
The independent five-minute generation schedule is retired. The one-minute
sync timer still enforces the station's configured polling interval.

The generator synthesizes a replacement when report content changes or
a valid regeneration condition applies, such as invalid media or an
explicit operator request. Its content fingerprint excludes announcer
and voice selection. Each publication records the actual rendered voice.
Failed or stale retrievals preserve existing audio and Ready-to-Air.
Empty complete retrievals are failures. Monitoring's configured
notification channel receives feed warnings, critical alerts and
incident recovery messages.

Publication requires valid audio and verified cue timing. Readiness
and the fingerprint commit together. The sync tick can dispatch bounded
local recovery after interruption, including while the feed is unavailable.
A temporarily inconsistent audio and Track timing window remains possible.
The observed 31 ms and 20.090 s recovery intervals are measurements.

1.22-E makes the existing malformed-media regression deterministic.
The accepted test-only commit changes no playback behavior.

The deprecated generation timer stays in the product as an elapsed,
non-persistent compatibility unit under its original name. Its only
activation target is the watcher. Leave the timer disabled after
installation. The sync service reports a systemd dependency failure if the
watcher is missing or inactive. Follow the [station runbook](r0150_installation.md)
to stage the watcher and tmpfiles before the protected Update Center
advances application source. The signed managed-unit policy and protected
runtime generation are unchanged.

Accepted minor findings remain visible for later review. The retry log can
misdescribe a superseded report. A failed first publication can leave an
unready Track row without a file. Piper provenance lacks a model hash.
The passing 744-test corrective evidence is `qualification.log`.
The guest console evidence cannot independently prove QEMU network
isolation because the command line was not retained. Guest service bodies
used fixtures, so post-cutover acceptance is the first complete station
systemd, application and PostgreSQL qualification.
