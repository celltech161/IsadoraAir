## Included changes

### Remote DJ 2.17A

- Every Remote Mic gate command is bound to the authenticated caller's current
  live signaling session and the browser's expected session identity. A stale,
  replaced, observer, or otherwise non-owning browser cannot change microphone
  authority.
- Permission loss forces a live Remote Mic gate off. A new command requires a
  fresh operator click; conflicts are never automatically retried.
- `remote_dj.emergency_mute` and `remote_dj.force_disconnect` are configurable
  capabilities granted by default only to Station Administrator. Emergency
  mute can only close and latch the gate; releasing it never opens the mic.
- Ordinary Remote Host microphone authority remains schedule-bound. The
  superuser remains the break-glass route.

Accepted implementation tip:
`e92083ba56faf76920f72035aa2493ea1306e4ef`.

### Monitoring recovery-email lifecycle

- Recovery is emitted only when the current incident had a qualifying warning
  or critical notification attempt. Delivery success is tracked separately;
  an SMTP failure still preserves recovery eligibility.
- Cooldown suppression, disabled severities, and absence of recipients do not
  fabricate eligibility. Critical eligibility survives a later warning, and
  preference changes take effect through the existing poll cycle.
- Incident attribution is persisted compatibly, cleared on resolution or
  deactivation, and handled conservatively across restart and legacy state.
- Thresholds, debounce behavior, dashboard cards, SystemEvents, and other
  operational-email paths are unchanged.

Independent commit:
`46244a378eb89cd461c9baff71287706a8a00910`.

### Start Next visual refinement

- Desktop width is 65% of the former slot and the control stretches with its
  neighboring deck cards; corners are less rounded.
- The normal and hover greens use dark foregrounds with measured WCAG AA
  contrast. The hover foreground is lighter than normal but remains dark green:
  a pale foreground on the requested light-green hover cannot meet 4.5:1.
- Mobile keeps a compact 44–56 px control rather than inheriting desktop
  height. Disabled and keyboard-focus states are explicit.
- No Start Next authorization, request, engine, fade, queue, transport,
  Manual-mode, or occurrence-accounting code changed.
