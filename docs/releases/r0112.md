# r0112 — spoken render worker restart authority

r0112 is a protected-runtime bridge release with **no station feature
change**. It expands Update Center's finite, closed restart authority so a
future application release can declaratively restart the already-installed and
managed `isadoraair-spoken-render-worker`.

D3C is not part of this release. After r0112 installation and acceptance, the
frozen Native Regular Produced Content and TEST/NO-AIR candidate moves to
**r0113**.

## Exact authority change

Before r0112, application and protected Update Center code accepted these
restart identities:

```text
isadoraair-gunicorn
isadoraair-engine
isadoraair-monitoring
isadoraair-encoders
isadoraair-rbds
```

r0112 adds exactly:

```text
isadoraair-spoken-render-worker
```

The deterministic restart order becomes:

```text
isadoraair-gunicorn
isadoraair-engine
isadoraair-monitoring
isadoraair-spoken-render-worker
isadoraair-encoders
isadoraair-rbds
```

Restartability remains an explicit code allowlist. It is not inferred from
systemd, unit templates, or the signed managed-unit policy. For example,
`isadoraair-render.service` remains managed and `ENABLE_NOW`, but it is not
valid in `services_requiring_restart`.

## Protected runtime

r0112 transitions:

```text
generation:                 13 → 14
runtime version:            11 → 12
manifest protocol:           5 → 5
wire protocols:           3, 4 → 3, 4
bootstrap protocol:          1 → 1
```

Runtime 12 adds explicit restart authority and ordering for the already-managed
spoken render worker. It changes no release-manifest schema, daemon wire
protocol, bootstrap protocol, or managed-unit activation semantics.

The generation-13 signed policy already contains:

```text
isadoraair-spoken-render-worker.service → ENABLE_NOW
```

That policy inventory is byte-for-byte unchanged in generation 14. The worker
already exists and remains enabled/running; r0112 adds only authority for
future release manifests to request its restart.

## r0112 installation actions

r0112 has no migrations, migration authorization companion, requirements or
apt changes, systemd unit-file changes, nginx change, static collection, or
product runtime-component change.

The release itself declares only:

```text
protected runtime handoff: generation 14 / runtime 12
restart:                    isadoraair-gunicorn
```

Gunicorn restarts because the Django-side manifest validator and planner
changed. The spoken render worker does **not** restart for r0112 because its
application code is unchanged here. Generation 13 can parse and execute this
bridge release: r0112 asks generation 13 to restart only the already-recognized
Gunicorn service, stages and verifies generation 14 through the existing
supervisor, and allows generation 14 to continue the durable job.

## Safety boundaries

r0112 changes no engine, GStreamer, renderer implementation, spoken worker
application code, Active Messages behavior, OGRemote behavior, Produced
Content model, recipe, TEST/NO-AIR feature, package, service template, or
station data. Native Active Message airing remains closed:

```python
NATIVE_AIRING_AVAILABLE = False
```

No deployment or station cutover is part of release packaging.

## Expected Update Center sequence

1. Fetch and validate the trusted r0112 release.
2. Resolve its immutable introducing commit.
3. Validate generation 14's descriptor, inventory, unchanged policy and
   `primary-release` attestation.
4. Stage generation 14 in the inactive protected-runtime slot.
5. Have the existing supervisor independently verify and activate generation
   14, preserving the durable job across handoff.
6. Continue under runtime 12.
7. Apply no migration, package, unit, nginx or collectstatic action.
8. Advance application source to the immutable r0112 target.
9. Restart `isadoraair-gunicorn` only.
10. Run postflight checks and clean staging.

## Acceptance checklist

- Installed application HEAD is the immutable commit that introduced
  `deploy/releases/r0112.json`.
- Protected runtime reports generation 14 and runtime version 12.
- Manifest protocol remains 5, wire protocols remain 3/4, and bootstrap
  protocol remains 1.
- The signed managed-unit policy matches generation 13 byte-for-byte and the
  spoken worker remains `ENABLE_NOW`.
- Update Center accepts a synthetic future manifest containing Gunicorn plus
  the spoken worker and orders them identically in application and protected
  planning.
- `isadoraair-render`, arbitrary managed services and unknown names remain
  invalid restart targets.
- Gunicorn has a new activation timestamp; the spoken worker, engine, renderer,
  validation, monitoring, encoders and RBDS do not restart solely for r0112.
- `active_messages.services.NATIVE_AIRING_AVAILABLE` remains `False`.
- `manage.py makemigrations --check --dry-run` reports `No changes detected`.
- No D3C files or migrations are present in the r0112 release surface.

## Runtime Recovery

After successful r0112 installation and acceptance, build and validate a fresh
**Runtime Recovery** payload for protected-runtime generation 14. The existing
generation-13 recovery payload is no longer current after this transition.
