## A — Deck mixer continuity

**The inherited defect.** The engine mixes its decks in a deck `audiomixer` before the master mixer. That deck mixer
was not live: it advanced its output timeline only while it had a deck to mix. When the last deck was released (an
exhausted hour, a live-fill proposal still in flight) it stopped, while the master mixer and the pipeline clock kept
running. The next deck was linked at the current running time, so the deck mixer first had to regenerate the whole
idle span as silence, which it did at only ~4.5–5.5x real time. Measured on r0145: after a 240 s idle the deck mixer
was 240 s behind and the new song stayed inaudible for the whole measurement window; even a 15 s idle left the song
inaudible for over 5 s, while its PlayEvent had already been recorded. Dead air was roughly idle/4.5.

**The correction.**

- The deck mixer is now constructed live (`force-live=true`). The property can be set only at construction, so the
  engine builds the element with it (`make_deck_mixer`) and checks that it reads back true. A live mixer aggregates on
  the clock even with no deck, so its timeline keeps pace through an idle and its output is digital silence.
- The deck bus has one fixed format: a capsfilter immediately after the deck mixer requires
  `audio/x-raw,format=S16LE,rate=<station rate>,channels=2,layout=interleaved` (`make_deck_bus_caps`). Without it, a
  live mixer with no deck negotiated S32LE from downstream and then renegotiated to the first deck's S16LE while
  running; that transition corrupted deck audio and correlated with a native crash in qualification. With the fixed
  format the mixer negotiates once, from startup. Decks are converted to it by their own `audioconvert`.
- The master mixer, the pipeline clock, the mixer `latency`, `min-upstream-latency` and `output-buffer-duration`,
  deck pad offsets, gains, ducking, crossfades, Voice Track timing and PlayEvent authority are unchanged.

**Result (measured).** After 15–240 s zero-deck idles at 44.1 and 48 kHz the deck mixer stays within 0.022 s of the
clock, there is no catch-up burst (1.00–1.02x), the next song's audio reaches the program 0.26–0.30 s after its deck
exists, and exactly one PlayEvent is recorded per start. In the Remote DJ real-media scenarios the deck, duck and
program PCM of a reference tone is as clean as r0145's (residual at 16-bit quantization level, no discontinuities).

**Startup diagnostic.** The engine logs `Deck mixer: audiomixer force-live=True` at startup. If the installed GStreamer
cannot construct a live mixer, the engine falls back to the old non-live mixer, logs `force-live=False` and records a
Monitoring warning "Deck mixer is not live (idle-start catch-up risk)". **That fallback is the old defective
behaviour, not the correction.** The mandatory station preflight below checks for it, and for the mixer's actual
fixed-format output, before installation.

## Mandatory station GStreamer preflight (installation gate)

Before r0146 is installed on **any** station, both of these checks must pass on that station, at its own configured
sample rate and with its own installed GStreamer runtime (the exact, self-contained procedure is in
`r0146_installation.md`):

1. **Gate A, construct-time capability:** the installed Python/GObject/GStreamer creates the deck `audiomixer` with
   `force-live=true` and it reads back `True`. A fallback to the inherited non-live mixer is a blocking failure.
2. **Gate B, actual fixed-format output:** a standalone probe at the station sample rate shows the mixer source
   negotiating `audio/x-raw,format=S16LE,rate=<station rate>,channels=2,layout=interleaved` exactly once, from zero-pad
   startup, with no unexpected renegotiation, no DISCONT, no GStreamer bus error, clock-driven output and digital
   silence during zero-pad idle.

Both checks are mandatory. A station must not install r0146 if either check fails, is skipped or cannot be completed
safely. KOGR's engineering preflight (GStreamer 1.28.2, 44100 Hz) is supporting evidence only. **WRJE must pass both
checks independently** (its GStreamer version and installed release are unverified and its preflight is pending); that
is a WRJE deployment blocker, not a barrier to publication of a release whose installation remains separately
authorized. The preflight is an operator gate, not an UpdateCenter action.

## Limitations (accepted; not remediated in r0146)

1. **Claimed-but-unaired recovery** remains roadmap 1.21-B. A PlayEvent is recorded when the song's first real audio
   crosses the deck admission boundary, about 0.27 s before it is heard; a failure after that point is not recovered.
   That PlayEvent admission authority lies upstream of the deck mixer and is unchanged by r0146.
2. **Durable crash / power-outage checkpoint recovery** remains roadmap 1.21-C.
3. **Roadmap 1.21-D (live-fill and exhausted-hour scheduling).** No independent normal live-fill or exhausted-hour
   scheduler defect was established; r0146 contains no separate scheduler correction.
4. **Roadmap 1.21-E (Monitoring and automatic recovery).** Expanded Monitoring continuity classification and automatic
   dead-air recovery are **not implemented** in r0146.
5. **Ordinary outgoing-tail truncation (F14b)** remains separately tracked; r0146 does not measurably change it.
6. **Decoder starvation.** Ordinary-path preparation starvation and mid-song decoder starvation remain separately
   tracked defects; r0146 does not correct either.
7. **The non-live fallback remains defective** and does not count as continuity protection. Stronger release and
   preflight diagnostics for it are a possible separate requirement; the mandatory preflight above blocks installation
   where it would be used.
8. **The deck bus is 16-bit.** 24-bit and floating-point files still play; their samples are reduced to 16 bits by
   GStreamer's audio converter before mixing (r0145 mixed in the first deck's format, 16-bit in every measured case).
9. **Dithering.** The deck-bus output is fixed at S16LE. IsadoraAir does not explicitly guarantee portable dithering
   behavior across different GStreamer installations.
10. **GStreamer version.** r0146 does not upgrade the system GStreamer runtime to 1.28.9 or any other version. It uses
    the compatible station-installed runtime, subject to the mandatory preflight above.
11. **Hour Refill policy is unchanged.**
12. The exact native cause of the crash seen in the unfixed Phase A candidate was **not** identified; the fixed format
    removed the correlated format change, and the crash and audio corruption did not recur in the tested
    configurations.

Not included: no GStreamer upgrade, no Hour Refill policy change, no live-fill or recovery feature.

## Operational impact

There is no migration: `migrations_required` is empty and `migration_compatibility` is `null`. There are no new
packages, Python requirements, static assets, collectstatic, nginx changes, systemd units, manual bootstrap or
protected-runtime changes: `protected_runtime` is `null`. Restart exactly:

1. `isadoraair-engine`

The only changed production module is the engine's; its changed code runs only when the engine builds its pipeline,
so Gunicorn, Monitoring, the encoders, RBDS and the workers keep running. The engine restart **interrupts program
audio** briefly; install in an approved maintenance window. A station on r0144 or later installs from an Update
Center with the **engine restart safeguard**, which refuses the installation while a studio microphone or Remote DJ is
live or engine status is unknown. Do not override it to install. A station on an earlier release still receives every
intervening migration and restart in its cumulative plan.

Publication does not authorize installation: each station requires separate preflight, installation authorization and
operational acceptance; see `r0146_installation.md`.
